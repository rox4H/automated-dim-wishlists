# Weapon Wishlists

Choose a wishlist and add it to DIM, or suggest a roll.

## Use a wishlist

- [Curated wishlist](https://raw.githubusercontent.com/rox4H/automated-dim-wishlists/main/exports/d2wd_curated.txt) — project picks.
- [Community wishlist](https://raw.githubusercontent.com/rox4H/automated-dim-wishlists/main/exports/d2wd_community.txt) — player suggestions.

In DIM, open **Settings → Wish Lists**, paste the chosen URL, and save. Matching items show a thumbs-up. Open an item to see its suggested perks, or search `is:wishlist`.

## Suggest a roll

Open a [recommendation issue](https://github.com/rox4H/automated-dim-wishlists/issues/new?template=recommendation-proposal.yml). Submit one roll per issue. Fill in the mode, a short name, description, exact weapon version (for example, `avalanche_s5`), and four perks. Do not include private information.

To report an error, use the [correction issue](https://github.com/rox4H/automated-dim-wishlists/issues/new?template=data-correction.yml).
